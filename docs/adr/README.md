## Что считается архитектурным решением

Решение, которое затрагивает несколько частей системы, трудно обратимо либо влияет на атрибуты качества. Остальное решается в коде и в ревью.

## Как добавить запись

1. Взять следующий свободный номер (номера не переиспользуются)
2. Скопировать форму из [`docs/templates/adr.md`](../templates/adr.md)
3. Заполнить; раздел альтернатив — не менее двух вариантов с реальными доводами
4. Добавить строку в эту таблицу
5. Отправить запросом на слияние; остальные участники подтверждают решение в ревью
