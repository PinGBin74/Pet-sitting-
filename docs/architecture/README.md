# Архитектурные диаграммы

Все диаграммы — текст в формате Mermaid. Отрисовываются GitHub при просмотре файла. Проверяются конвейером: диаграмма, которая не отрисовывается, не проходит.

Начать чтение лучше с [обзора архитектуры](./overview.md).

## Что здесь есть

| Файл | Что показывает | Для кого | На какой вопрос отвечает |
|---|---|---|---|
| [`c4/context.mmd`](./c4/context.mmd) | Система, три роли пользователей, внешние системы | Новый человек в проекте, преподаватель | С чем граничит система и кто ею пользуется? |
| [`c4/container.mmd`](./c4/container.mmd) | Запускаемые части и хранилища | Разработчик, эксплуатация | Из чего система состоит и на чём сделана? |
| `sequence/` | Запрос и подтверждение брони, включая отказы | Разработчик сценария | Что в каком порядке вызывается? |
| `data/model.mmd` | Сущности, атрибуты, связи, ключи | Тот, кто пишет миграции | Как устроены данные? |

Перечень операций API — в [`../api/resources.md`](../api/resources.md).

## Чего здесь нет и почему

| Чего нет | Почему |
|---|---|
| Уровень компонентов C4 | Компонентов пока мало, диаграмма повторила бы структуру каталогов |
| Уровень кода C4 | Устаревает быстрее, чем пишется; заменяется чтением кода |
| Диаграмма развёртывания (Docker, Compose) | Контейнер C4 — не контейнер Docker; способ запуска — отдельная диаграмма |
| Карта контекстов предметной области | Лежит в [`../domain/context-map.mmd`](../domain/context-map.mmd) |
| Контексты на диаграмме контейнеров | Контекст — граница модели, контейнер — граница развёртывания. Все четыре контекста — модули одного контейнера `api` (ADR-0003) |

## Как обновлять

Диаграмма правится **в том же запросе на слияние**, который меняет систему. Правило проверяется на ревью: изменение, добавляющее службу в `compose.yaml` без правки `c4/container.mmd`, не принимается.

Локальная проверка перед коммитом:

```bash
npx --yes @mermaid-js/mermaid-cli -i docs/architecture/c4/context.mmd -o /tmp/out.svg
```

## Соглашение об оформлении C4

C4 рисуется через `flowchart`, потому что встроенная поддержка `C4Context` в Mermaid неустойчива между версиями. Подписи — в тексте узла через `<br/>`: название, вид и технология курсивом, назначение одной строкой. Хранилища — узлы формы `[( )]`. Классы стилей:

| Класс | Что обозначает | Цвет |
|---|---|---|
| `actor` | Человек или роль | голубой |
| `sys` | Наша система или её часть | оранжевый |
| `store` | Хранилище данных | зелёный |
| `ext` | Внешняя система | серый |

У каждой связи — что передаётся и каким протоколом; двусторонних стрелок нет.
