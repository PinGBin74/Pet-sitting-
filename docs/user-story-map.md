# Карта пользовательских историй

Версия 0.1 (05.10.2026).

---

## Активности (позвоночник пути)

| Стать хостом | Подготовить питомца | Найти хоста | Забронировать | Передержка | Завершить |
|---|---|---|---|---|---|

## Полная карта

**Активность: Стать хостом**
- Задача: создать профиль и пройти проверку
  - MVP · **S1** Как хост, я хочу создать профиль с районом, ценой за сутки, вместимостью и фото, чтобы владельцы могли меня найти
  - MVP · **S2** Как модератор, я хочу видеть очередь заявок хостов и одобрять или отклонять их с причиной, чтобы на платформе оставались только проверенные хосты
  - v1.1 · Как хост, я хочу видеть статус своей заявки, чтобы понимать, когда ждать решения
  - v1.2 · Как хост, я хочу загрузить документы для расширенной проверки, чтобы получить значок повышенного доверия

**Активность: Подготовить питомца**
- Задача: рассказать о питомце один раз
  - MVP · **S3** Как владелец, я хочу создать карточку питомца (вид, порода, вес, прививки, особенности), чтобы не повторять данные при каждой брони
  - v1.1 · Как владелец, я хочу хранить нескольких питомцев, чтобы бронировать для любого из них
  - v1.2 · Как владелец, я хочу, чтобы бронь блокировалась при просроченных прививках, чтобы не рисковать здоровьем питомцев

**Активность: Найти хоста**
- Задача: подобрать подходящего хоста
  - MVP · **S4** Как владелец, я хочу искать проверенных хостов по району и датам, чтобы видеть только тех, кто свободен
  - v1.1 · Как владелец, я хочу фильтры (вид животного, цена, наличие двора), чтобы быстрее выбрать
  - v1.2 · Как владелец, я хочу сортировку по рейтингу, чтобы видеть лучших выше

**Активность: Забронировать**
- Задача: договориться о передержке
  - MVP · **S5** Как владелец, я хочу отправить хосту запрос брони на даты с карточкой питомца, чтобы хост сразу видел все данные
  - MVP · **S6** Как хост, я хочу подтвердить или отклонить запрос, чтобы управлять своим календарём
  - v1.1 · Как хост, я хочу задать лимит одновременных питомцев, чтобы не принимать больше, чем могу
  - v1.2 · Как владелец, я хочу онлайн-оплату брони, чтобы не передавать деньги лично

**Активность: Передержка**
- Задача: быть в курсе, как питомец
  - MVP · **S7** Как хост, я хочу прикреплять фотоотчёты к текущей брони, чтобы владелец видел, что с питомцем всё в порядке
  - MVP · **S8** Как владелец, я хочу видеть отчёты по своей брони, чтобы быть спокойным в отъезде
  - v1.1 · Как владелец, я хочу получать уведомление о новом отчёте, чтобы не заходить без повода
  - v1.2 · Как владелец, я хочу кнопку SOS, чтобы быстро связаться с ветклиникой в экстренной ситуации

**Активность: Завершить**
- Задача: отменить или оценить
  - MVP · **S9** Как владелец, я хочу отменить бронь, чтобы освободить даты хоста, если планы изменились
  - MVP · **S10** Как владелец, я хочу оставить отзыв о хосте после завершения брони, чтобы другие видели его репутацию
  - v1.1 · Как хост, я хочу ответить на отзыв, чтобы объяснить спорные ситуации
  - v1.2 · Как владелец, я хочу повторить прошлую бронь в один шаг, чтобы не заполнять всё заново

**Следующие релизы (идеи вне MVP)**
- v1.1: услуга **выгула**; уведомления; фильтры; несколько питомцев
- v1.2: онлайн-оплата и комиссия; страховой сбор; автоблокировка по прививкам; SOS
- v2.0: груминг, подписки, новые районы, партнёрства

## Позвоночник MVP

Хост создаёт профиль (S1) → модератор одобряет (S2) → владелец заводит карточку питомца (S3) → находит хоста по району и датам (S4) → отправляет запрос брони (S5) → хост подтверждает (S6) → хост отправляет фотоотчёт (S7) → владелец смотрит отчёты (S8) → отменяет бронь, если надо (S9) → оставляет отзыв (S10).

Это минимальный сквозной путь: убрав любой шаг, получим неработающий сценарий. Исключение: S9 (отмена) вторична для «счастливого пути», но без неё места не освобождаются, поэтому остаётся в MVP.

## Критерии приёмки (истории позвоночника)

### S1. Профиль хоста

**Сценарий 1. Успешное создание**
- Дано: хост авторизован, профиля ещё нет
- Когда: он заполняет район, цену за сутки, вместимость, загружает фото и отправляет
- Тогда: профиль создан со статусом «на проверке» и не виден в поиске

**Сценарий 2. Неполные данные**
- Дано: хост не указал район
- Когда: он отправляет форму
- Тогда: профиль не создан, показано сообщение, какое поле обязательно

**Сценарий 3. Вместимость вне допустимых значений**
- Дано: хост ввёл вместимость 0 или отрицательное число
- Когда: он отправляет форму
- Тогда: форма не принята, показано допустимое значение

### S2. Модерация хостов

**Сценарий 1. Одобрение**
- Дано: в очереди есть заявка со статусом «на проверке»
- Когда: модератор одобряет её
- Тогда: статус «проверен», хост виден в поиске, решение записано в историю

**Сценарий 2. Отклонение с причиной**
- Дано: в очереди есть заявка
- Когда: модератор отклоняет её и указывает причину
- Тогда: хост не виден в поиске, причина сохранена и показана хосту

**Сценарий 3. Отклонение без причины**
- Дано: модератор нажимает «отклонить»
- Когда: поле причины пусто
- Тогда: решение не сохранено, показано требование указать причину

### S3. Карточка питомца

**Сценарий 1. Создание карточки**
- Дано: владелец авторизован
- Когда: он заполняет вид, породу, вес, дату последней прививки и особенности
- Тогда: карточка сохранена и доступна при создании брони

**Сценарий 2. Неверный вес**
- Дано: владелец вводит вес 0 или отрицательный
- Когда: сохраняет карточку
- Тогда: карточка не сохранена, показано сообщение об ошибке

**Сценарий 3. Дата прививки в будущем**
- Дано: владелец указал дату прививки позже сегодняшней
- Когда: сохраняет карточку
- Тогда: сохранение отклонено с пояснением

### S4. Поиск хостов

**Сценарий 1. Есть подходящие хосты**
- Дано: в районе есть проверенные хосты, свободные на выбранные даты
- Когда: владелец задаёт район и даты
- Тогда: он видит список этих хостов с ценой и отметкой «проверен»

**Сценарий 2. Нет подходящих**
- Дано: в районе нет свободных хостов на эти даты
- Когда: владелец выполняет поиск
- Тогда: показано «Свободных хостов нет», предложено изменить даты

**Сценарий 3. Дата в прошлом**
- Дано: выбрана дата начала раньше сегодняшней
- Когда: владелец запускает поиск
- Тогда: поиск не выполняется, показано сообщение о допустимых датах

**Сценарий 4. Непроверенный хост**
- Дано: хост имеет статус «на проверке» или «отклонён»
- Когда: владелец ищет в его районе
- Тогда: этот хост в списке не отображается

### S5. Запрос брони

**Сценарий 1. Успешный запрос**
- Дано: хост свободен на даты, у владельца есть карточка питомца
- Когда: владелец отправляет запрос
- Тогда: создана бронь со статусом «ожидает подтверждения», хост видит карточку питомца

**Сценарий 2. Даты заняты**
- Дано: пока владелец смотрел профиль, хост принял другую бронь на эти даты и достиг вместимости
- Когда: владелец отправляет запрос
- Тогда: бронь не создана, показано «Хост уже занят», предложены другие хосты

**Сценарий 3. Нет карточки питомца**
- Дано: у владельца нет ни одной карточки
- Когда: он пытается отправить запрос
- Тогда: запрос не отправлен, предложено создать карточку

### S6. Подтверждение хостом

**Сценарий 1. Подтверждение**
- Дано: бронь «ожидает подтверждения», даты свободны
- Когда: хост подтверждает
- Тогда: статус «подтверждена», владелец получает уведомление, даты заняты в календаре хоста

**Сценарий 2. Отклонение**
- Дано: бронь «ожидает подтверждения»
- Когда: хост отклоняет
- Тогда: статус «отклонена», владелец уведомлён, даты свободны

**Сценарий 3. Конфликт при подтверждении**
- Дано: хост уже подтвердил другую бронь на те же даты, вместимость исчерпана
- Когда: он пытается подтвердить вторую
- Тогда: подтверждение отклонено с пояснением

### S7. Фотоотчёт хоста

**Сценарий 1. Добавление отчёта**
- Дано: бронь подтверждена, сегодня внутри срока передержки
- Когда: хост загружает фото и текст
- Тогда: отчёт виден в брони с временем отправки

**Сценарий 2. Бронь не активна**
- Дано: бронь отклонена, отменена или завершена
- Когда: хост пытается добавить отчёт
- Тогда: отчёт не добавлен, показано, что отчёты доступны только по активной брони

**Сценарий 3. Неподдерживаемый файл**
- Дано: хост выбрал файл, который не является изображением
- Когда: он отправляет отчёт
- Тогда: отчёт не сохранён, показано допустимые форматы

### S8. Просмотр отчётов

**Сценарий 1. Есть отчёты**
- Дано: в брони есть хотя бы один отчёт
- Когда: владелец открывает бронь
- Тогда: он видит отчёты в порядке отправки, новые сверху

**Сценарий 2. Отчётов пока нет**
- Дано: бронь подтверждена, отчётов нет
- Когда: владелец открывает бронь
- Тогда: показано «Отчётов пока нет»

**Сценарий 3. Чужая бронь**
- Дано: бронь принадлежит другому владельцу
- Когда: пользователь открывает её по ссылке
- Тогда: доступ запрещён

### S9. Отмена брони

**Сценарий 1. Отмена до начала**
- Дано: бронь подтверждена, начало в будущем
- Когда: владелец отменяет
- Тогда: статус «отменена», даты освобождаются, хост уведомлён

**Сценарий 2. Отмена уже начавшейся**
- Дано: передержка уже идёт
- Когда: владелец пытается отменить
- Тогда: отмена недоступна, показано, что делать (связаться с хостом)

**Сценарий 3. Повторная отмена**
- Дано: бронь уже отменена
- Когда: владелец нажимает «отменить» снова
- Тогда: состояние не меняется, показан текущий статус

### S10. Отзыв

**Сценарий 1. Оставить отзыв**
- Дано: бронь завершена
- Когда: владелец ставит оценку 1–5 и пишет текст
- Тогда: отзыв сохранён и виден в профиле хоста

**Сценарий 2. Бронь не завершена**
- Дано: бронь ещё идёт
- Когда: владелец пытается оставить отзыв
- Тогда: отзыв не принят, показано, что отзыв доступен после завершения

**Сценарий 3. Повторный отзыв**
- Дано: отзыв по этой брони уже есть
- Когда: владелец пытается оставить второй
- Тогда: второй не принят

## Приоритизированный бэклог

| Приоритет | История | Обоснование |
|---|---|---|
| **Must** | S1 Профиль хоста | Без хоста нечего искать |
| **Must** | S2 Модерация хостов | Ядро доверия, закрывает боль №1 |
| **Must** | S3 Карточка питомца | Данные для брони, закрывает боль №3 |
| **Must** | S4 Поиск хостов | Вход в сценарий владельца |
| **Must** | S5 Запрос брони | Ядро продукта |
| **Must** | S6 Подтверждение хостом | Бронь без подтверждения не работает |
| **Must** | S7 Фотоотчёт | Закрывает боль №2 |
| **Must** | S8 Просмотр отчётов | Отчёт бесполезен, если его не видно |
| **Must** | S9 Отмена брони | Иначе даты не освобождаются |
| **Must** | S10 Отзыв | Формирует репутацию хоста |
| **Should** | Статус заявки хоста | Снимает неопределённость ожидания |
| **Should** | Лимит питомцев у хоста | Безопасность и честная нагрузка |
| **Should** | Фильтры поиска | Ускоряют выбор |
| **Should** | Несколько питомцев у владельца | Частый случай |
| **Could** | Уведомление о новом отчёте | Удобство |
| **Could** | Ответ хоста на отзыв | Не влияет на проверяемую гипотезу |
| **Could** | Выгул как вторая услуга | Расширение; после проверки ядра |
| **Won't** | Онлайн-оплата, комиссии | Вынесено за границы, см. `requirements.md` |
| **Won't** | Подписка и платные курсы | Вынесено за границы |
| **Won't** | Автоблокировка по прививкам, SOS | Вынесено за границы |
| **Won't** | Несколько районов | Вынесено за границы |
