# Передержка рядом

Платформа, где владелец кошки или собаки находит проверенного модератором частного хоста для передержки на время отъезда, бронирует его на свои даты и получает фотоотчёты о питомце.

**Команда**: Ирина (@irenandko), Артур (@whohess), Антон (@PinGBin174)
**Курс**: Технологии разработки программных систем, ОмГТУ, 09.03.01
**Предметная область**: передержка питомцев у частных хостов

## О проекте

Владельцы кошек и собак, уезжающие на 2–14 дней, сейчас ищут передержку в чатах и на досках объявлений, где нельзя проверить человека и неизвестно, как питомец проводит время. Мы делаем веб-сервис для одного городского района, в котором:

- хост создаёт профиль, а модератор вручную проверяет его и ставит отметку «проверен»;
- владелец один раз заполняет карточку питомца и ищет свободных проверенных хостов по району и датам;
- владелец отправляет запрос брони, хост подтверждает или отклоняет;
- во время передержки хост публикует фотоотчёты, после завершения владелец оставляет отзыв.

Подробности — в [docs/requirements.md](docs/requirements.md).

## Как внести изменение

1. Обновите основную ветку: `git switch main && git pull`
2. Создайте ветку от `main`: `git switch -c feat/SCRUM-<номер>-<короткое-описание>`
3. Внесите изменения, закоммитьте по [соглашению о коммитах](CONTRIBUTING.md#формат-коммитов)
4. Добавьте запись в [CHANGELOG.md](CHANGELOG.md)
5. Отправьте ветку и откройте запрос на слияние — шаблон описания подставится автоматически
6. Дождитесь зелёного конвейера и ревью другого участника, затем слейте способом squash

Прямая запись в `main` запрещена. Подробные правила — в [CONTRIBUTING.md](CONTRIBUTING.md).

## Настройка окружения разработчика

Нужны Git и Python (для локальных хуков).

```bash
git clone <адрес репозитория>
cd <папка репозитория>

# Окончания строк: Windows
git config --global core.autocrlf true
# Окончания строк: macOS и Linux
git config --global core.autocrlf input

# Локальные хуки: проверяют оформление до коммита
pip install pre-commit
pre-commit install
pre-commit run --all-files
```
